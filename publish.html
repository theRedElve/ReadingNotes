  1. 第 1 步
    连接 GitHub

    粘贴你的 Fine-grained 令牌，点「保存令牌」。令牌只保存在当前浏览器，可随时清除。

    第一次用？展开看怎么创建令牌
    1. 登录 GitHub，点右上角头像 → Settings
    2. 左侧最下方 → Developer settings → Personal access tokens → Fine-grained tokens
    3. 点 Generate new token，Name 随便填（例如 ReadingNotes），Expiration 自选
    4. Repository access 选 Only select repositories，只勾选 ReadingNotes
    5. Permissions → Repository permissions → Contents 设为 Read and write
    6. 点 Generate token，复制以 github_pat_ 开头的令牌（只显示这一次）
    7. 回到本页粘贴并点「保存令牌」，右上角变成「已连接 GitHub」即成功

    令牌到期后重新生成一个替换即可；换设备或清理浏览器数据后需要重新保存。
