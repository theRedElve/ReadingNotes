怎么让更新真正上线

  1. 在这里增删改摘录，内容会即时写入本地草稿，同一浏览器的书摘馆、影视馆与主题馆立即生效。
  2. 首次使用：打开「全部内容」页底部的「发布上线」，保存一个 Fine-grained GitHub 令牌（仅需本仓库 Contents 读写权限）。
  3. 之后每次保存、删除或恢复都会自动提交到 main 分支，GitHub Pages 约 1 分钟后对所有访客生效；也可在那里点「立即发布」。备用方式仍是导出 excerpts.js 后手动上传。

主题（可多选）*

已有书目可直接选择，会自动带入作者、出版社与年份；列表里没有时选择「＋ 新增书籍…」。

带 * 的字段为必填，主题可多选。书籍摘录会按书名归入「书摘馆」，影视台词归入「影视馆」，两者都会按所选主题出现在「主题馆」；只有书籍能进入「今日一页」。保存后写入本地草稿，不会改动已上传的文件。
